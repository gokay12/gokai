Photoshop
MCP Agent eklentisi
Bekleniyor
Photoshop'u açın → Eklentiler › Photoshop MCP Agent → Connect. Paneldeki Connect on Launch işaretliyse bu adım otomatiktir.
Ai
Illustrator
MCP Agent eklentisi
Bekleniyor
Illustrator'da önce bir dosya açın → Pencere › Uzantılar › Illustrator MCP Agent. Panel açılınca kendiliğinden bağlanır; açık bıraktığınız sürece her açılışta yeniden bağlanır.
Pr
Premiere Pro
MCP Bridge (CEP) paneli
Bekleniyor
Premiere'de bir proje açın → Pencere › Uzantılar › MCP Bridge (CEP). Köprü panel açılınca kendiliğinden başlar; paneli kapatmayın.
Ae
After Effects
AE MCP Bridge paneli
Bekleniyor
Panel After Effects açılınca kendiliğinden başlar. Bağlanmazsa Pencere › Uzantılar › AE MCP Bridge'ı açın; kurulumdan sonraki ilk açılışta Mac'i yeniden başlatmak gerekebilir.
